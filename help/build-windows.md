# Сборка Laba2 под Windows

## Требования

- Visual Studio 2022 (17.x) с установленными компонентами «Разработка классических приложений на C++».
- CMake 4.1 или новее.
- Git не обязателен: исходники FLTK лежат в `third_party/fltk-1.4.5`.

FLTK 1.4.5 и все сторонние библиотеки собираются из исходников, поэтому интернет и менеджер пакетов не нужны. Внешних зависимостей, скачиваемых автоматически, у проекта нет.

## Сборка из командной строки

Откройте «Командную строку разработчика для Visual Studio 2022» (Developer Command Prompt), чтобы был доступен `cl.exe` и `ninja`/`cmake`.

```bat
cd путь\к\Laba2
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build --target Laba2Scan
ctest --test-dir build --output-on-failure
```

Команда `Laba2Scan` не зависит от FLTK и собирается быстрее всего. Графическое приложение `Laba2` собирается отдельно:

```bat
cmake --build build --target Laba2
```

Результат: `build\Laba2.exe` и `build\Laba2Scan.exe`.

## Сборка в CLion

1. File → Open, выбрать корень `Laba2` (не каталог `third_party`).
2. В настройках CMake выбрать генератор Ninja или «Visual Studio» и задать `CMAKE_BUILD_TYPE=Debug`.
3. Build → Build Project.

CLion создаёт свой каталог сборки (по умолчанию `cmake-build-debug`); ручная сборка в `build/` этому не мешает.

## Кодировка исходников

В `CMakeLists.txt` для MSVC включён флаг `/utf-8`, поэтому русский текст в строках и комментариях читается без настройки локали. Устанавливать кодовую страницу консоли вручную не нужно.

## Проверка

```bat
ctest --test-dir build --output-on-failure
```

Тесты `lab2_check_folder` и `lab2_check_folder_csv` прогоняют папку `task/Для проверки Lab2` с файлами BMP. Остальные тесты добавляются автоматически, если существуют каталоги `tests/data` и `tests/corrupt`.

## Возможные проблемы

- **«Не удаётся найти cl.exe»** — запущена обычная командная строка, а не Developer Command Prompt.
- **Ошибки линковки вида `fltk::fltk`** — не завершена сборка FLTK, повторите `cmake --build build` целиком: FLTK подключён через `add_subdirectory(... EXCLUDE_FROM_ALL)` и собирается как зависимость.
- **Ошибка `LNK4098` или «defaultlib 'LIBCMT' conflicts»** — в проекте принудительно включён статический MSVC runtime (`FLTK_MSVC_RUNTIME_DLL=OFF`). Не меняйте этот параметр по одному, иначе разъедутся настройки FLTK и приложения.
- **Антивирус блокирует запуск** — собранное приложение обращается к файлам по UNC-путям и каталогам; добавьте каталог сборки в исключения.
- **Путь к проекту содержит кириллицу или пробелы** — CMake 4.1 справляется с этим, но `ninja` иногда путает аргументы; в таком случае используйте генератор «Visual Studio».
